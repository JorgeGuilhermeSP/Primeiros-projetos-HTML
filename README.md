# 🌐 Primeiros Projetos HTML & Web Fundamentals

Este repositório reúne meus primeiros passos no desenvolvimento web. Ele documenta a minha evolução desde o entendimento das tags estruturais do HTML5 até a integração de páginas dinâmicas utilizando JavaScript, manipulação de dados (JSON/AJAX), estilização estrutural e comunicação básica com o backend (PHP).

## 📊 Estrutura do Repositório e Aprendizados

Os projetos e arquivos estão divididos pelo foco de aprendizado:

### 📑 Fundamentos de HTML5 (Estruturação)
* **`minhaprimeirawebpage.html` / `Teste_tags.html`:** Primeiros contatos com a estrutura básica de um documento web.
* **`Teste_ul_ol.html`:** Prática com listas ordenadas e não ordenadas.
* **`teste_tabela.html` / `tab_cabecalho_rodape.html`:** Construção de tabelas estruturadas com cabeçalho (`<thead>`), corpo (`<tbody>`) e rodapé (`<tfoot>`).
* **`teste_row_col.html`:** Estudos iniciais sobre alinhamento, linhas e colunas para a criação de layouts.

### 📝 Formulários e Integração com Backend
* **`formulario_html.html`:** Criação de campos de entrada de dados, validações nativas e tipos de inputs.
* **`formulario_php`:** Refatoração de estruturas de formulário focando na preparação dos dados para envio e recebimento via PHP.

### ⚡ Lógica de Programação e Dinamismo com JavaScript
* **`calculadora_JavaScript` / `Calculadora_IMC`:** Aplicação de lógica no front-end para capturar entradas do usuário, processar cálculos matemáticos e exibir o resultado em tempo real na tela.
* **`fibonacci`:** Implementação do algoritmo da sequência de Fibonacci utilizando loops em JavaScript para renderização dinâmica no navegador.

### 🔄 Manipulação de Dados e APIs (Conceitos Avançados)
* **`json`:** Estudos sobre o formato de dados JSON (JavaScript Object Notation), essencial para a comunicação entre sistemas.
* **`ajax`:** Introdução a requisições assíncronas (Asynchronous JavaScript and XML) para atualizar partes de uma página web sem a necessidade de recarregá-la completamente.
* **`gráfico_charts`:** Integração de bibliotecas externas de gráficos (como Chart.js) para renderizar dados estatísticos e visuais de forma dinâmica.

## 🛠️ Tecnologias Estudadas

* **HTML5** (Semântica e Estruturação)
* **JavaScript (ES6+)** (Lógica de programação no cliente e manipulação do DOM)
* **JSON & AJAX** (Tráfego de dados e requisições assíncronas)
* **PHP** (Conceitos iniciais de requisições no servidor)
